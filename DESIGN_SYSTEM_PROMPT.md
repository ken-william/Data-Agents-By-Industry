# Master Specification & Prompt System - Talk to Data V2 (Agent Hôte & Canvas Minimaliste Slime)

Ce document constitue la **Spécification Maître Complète** de la plateforme **"Talk to Data V2"** (BigData Paris 2026), rédigée pour implémenter l'**Agent Hôte Maître de Jeu**, l'**Orbe Gemini Live Slime Liquide 3D**, le **Canvas Minimaliste Unique** et le **Dock d'Extensions Sectorielles en bas d'écran**.

---

# 🎭 1. Architecture V2 : Agent Hôte & Dock Minimaliste

| Composant UI | Ancienne Approche | Nouvelle Spécification V2 |
| :--- | :--- | :--- |
| **Agent Hôte** | Multiples agents affichés en vrac. | **Master AI Host Unique** : Intercepte les JSON bruts BigQuery, extrait les métriques clés et les traduit en synthèse vocale purifiée. |
| **Page 2 Canvas** | Grille bento complexe avec historique. | **Canvas Minimaliste Unique** : Tableau de bord unique en verre dépoli au centre, sans historique de chat étouffant. |
| **Dock Scénarios** | Grilles de boutons massifs. | **Dock d'Extensions Gemini en Bas d'Écran** : Puces horizontales compactes alignées au bas du viewport (style NotebookLM / Gemini Enterprise). |
| **Orbe Live** | Sphère avec icône de micro statique. | **Blob Liquide Slime 3D** : Forme fluide organique en fusion sans icône de micro, pulsant de manière vivante. |
