# Master Specification & Prompt System - Talk to Data (Google Luminous Aurora Master Specification)

Ce document constitue la **Spécification Maître Complète** de la plateforme **"Talk to Data"** (BigData Paris 2026), rédigée d'après le design system **Google Luminous Aurora** avec fusion chromatique 4 couleurs, Orbe Live Chroma, SQL FlipCard phosphorescent et Sélecteur de Thèmes Événementiels.

---

# 🎨 1. Les 4 Thèmes Événementiels (Google Luminous Aurora)

| Identifiant du Thème | Nom & Ambiance Visuelle | Palette Chromatique Principale |
| :--- | :--- | :--- |
| **`cloud-next`** *(Défaut)* | **Vibrance Google Cloud Next** | Bleu `#4285F4`, Rouge `#EA4335`, Jaune `#FBBC05`, Vert `#34A853` sur fond marine `#050B24`. |
| **`gemini-aurora`** | **Gemini AI Official** | Cyan `#38BDF8`, Violet `#818CF8`, Magenta `#C084FC`, Rose Corail `#EC4899`. |

---

# 🔮 2. L'Aurore Animée CSS & Réfraction de Lumière

- **Fond "Luminous Aurora"** : Animation CSS fluide de 4 nébuleuses organiques (`.aurora-blob-1`, `.aurora-blob-2`, `.aurora-blob-3`, `.aurora-blob-4`) en fusion continue sous un filtre de flou éthéré `blur(120px)`.
- **Cartes Bento de Verre (`backdrop-blur-xl`)** : Plaques de verre dépoli `background: rgba(255, 255, 255, 0.04)` bordées de liserés d'argent et dégradés holographiques fins.

---

# ✍️ 3. Typographie Hybride Stylisée

- **`Talk to Data` & `live using`** : Sculptés en **Google Sans Flex** (Blanc étincelant `#FFFFFF`).
- **`conversational AI agents`** : Sublimé en **Instrument Serif** italique avec dégradé métallique brillant or, corail et rose (`.gradient-metallic`).

---

# 🎙️ 4. L'Orbe Live Chroma & SQL FlipCard Phosphorescent

- **Orbe Live Chroma** : Blob 3D fusionnant dynamiquement les 4 couleurs du thème avec 3 états physiques (Écoute, Réflexion, Parole).
- **SQL FlipCard** : Pivote à 180° avec flou de mouvement pour révéler les requêtes SQL phosphorescentes sur panneau de verre sombre.
